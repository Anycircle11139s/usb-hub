# USB hub

<br>
I made a USB hub for my self because My current one is really old and crusty, the case was falling apart and I thought making my own would be really cool. I followed the tutorial from fallout and managed to create a compact usb hub which I can take with me on holidays. I am really proud of my design and I can't wait to build it myself.
